# Cerdeutsch — Platform Belajar Bahasa Jerman A0–B2

Platform belajar bahasa Jerman interaktif dari tingkat dasar (A0/A1) hingga B2. Berjalan 100% di sisi klien (*client-side*), tanpa memerlukan API key, akun, atau server database.

## Fitur Utama
- **Modul Pemula (A0 - Erste Schritte):** Alfabet, vokal Umlaut (ä, ö, ü), dan 20 kalimat penyelamat.
- **Daily Starter Track:** Misi belajar harian 5 menit dengan *streak* dan badge.
- **4.000 Kosakata (A1–B2):** Dilengkapi artikel, bentuk jamak, konjugasi kata kerja, contoh kalimat, *flashcard*, dan *spaced repetition*.
- **Latihan & Simulasi Ujian:** Membaca (*Lesen*), Mendengarkan (*Hören*), Menulis (*Schreiben*), dan Berbicara (*Sprechen*).

## Menjalankan Secara Lokal

**Prasyarat:** Node.js

1. Instal dependensi:
   ```bash
   npm install
   ```
2. Jalankan server pengembangan:
   ```bash
   npm run dev
   ```
3. Build untuk produksi:
   ```bash
   npm run build
   ```
